# Миглена Иванова — Потапяне (LIQUID WORLD)

Всички файлове са в един root, без папки. Качи ги в GitHub repo → Settings → Pages → Deploy from branch.

- `index.html`, `style.css`, `script.js`, `photos.js` (снимките са вградени, затова работи и при двоен клик върху index.html), `photo01–08.webp` (оригиналните файлове), `share-image.jpg` (social preview).
- Адресът в `index.html` е за репото `miglena-liquid`.
- Звукът е синтезиран с Web Audio (без mp3) и се включва само от бутона „звук“.
- Управление: движение/докосване = сила върху водата; задържане = вихър и леща; колелце / стрелки / бърз вертикален swipe = нова материя. Последната сцена е кулминацията.
- Текстовете са абстрактни, без биографични факти.
